01 / CLEANING GUIDE

どの場所を、
相談したいですか？

項目を選ぶと、案内と準備例が変わります。
表示を試すだけの小さなデモです。

エアコン / ご紹介

機種と台数を、ひとつずつ。

通常タイプ・お掃除機能付きの清掃が案内されています。対応する機種や作業内容は、個別に確認します。

相談準備の例

  • メーカー・型番、台数
  • お掃除機能の有無（分かる範囲で）
  • 気になる状態と希望する時期

レンジフード / ご紹介

気になる汚れと、希望する範囲を。

レンジフード清掃の案内があります。設備の種類と、特に気になっているところを整理して相談します。

相談準備の例

  • 設備の種類や型番（分かる範囲で）
  • 気になる場所・汚れの状態
  • 希望する清掃内容と時期

浴室 / ご紹介

どこが気になるかを、具体的に。

浴室清掃についての案内があります。浴槽・床・壁など、気になる場所を言葉にして相談の準備をします。

相談準備の例

  • 気になる場所と状態
  • 浴室の設備・広さ（分かる範囲で）
  • 希望する清掃内容と時期

トイレ / ご紹介

設備と気になるところを整理。

トイレ清掃についての案内があります。設備の種類や、気になる箇所を整理して相談します。

相談準備の例

  • 設備の種類（分かる範囲で）
  • 気になる場所・汚れの状態
  • 希望する清掃内容と時期

準備項目は制作側の提案で、必須の受付条件ではありません。料金・作業範囲・日程・対応可否は、現在のご案内で確認が必要です。

02 / BEFORE CONSULTING

相談前に、
伝えることを整理。

分かるところからで大丈夫。
今の詳しい案内とあわせて確認してください。

  1. 01

    お願いしたい場所

    清掃したい設備、台数、気になる箇所を整理します。

  2. 02

    気になる状態

    汚れの状態や設備の種類など、分かる情報をまとめます。

  3. 03

    地域と希望する時期

    相談する市区町村と時期を整理します。日程は個別に確認が必要です。
